# 延时摄影 使用手册（v3.9）

> 开发者：Shenwenjun

> 索尼 ILCE‑7RM2 机内延时摄影 App。装好后在相机「应用程序列表」里打开。

---

## 一、按键一览

### 预览界面

| 按键 | 作用 |
|---|---|
| **ENTER** | 开始 / 停止间隔拍摄（开始前有 3 秒倒计时） |
| **快门全按（S2）** | 单张拍摄；拍摄运行中按下 = 停止 |
| **快门半按（S1）** | 对焦 |
| **上 / 下** | 间隔 −1 / +1 秒（5 秒 – 24:59:59） |
| **左 / 右** | 张数 −10 / +10（1–9999） |
| **FN** | 打开 / 关闭菜单 |
| **C2** | **循环切换预设文件**（1→2→3→4，跳过空文件，Toast 提示） |
| **C1** | **保存日志快照**：生成 `A7R2APP/SNAP-时间戳.TXT` |
| **删除键 / SK2** | 退出 App；拍摄运行中按下 = 停止拍摄 |

### 转盘（预览界面）

| 转盘 | 作用 |
|---|---|
| 前拨轮 | 光圈（A / M 档有效） |
| 后拨轮 | 快门（S / M 档有效）／调整曝光补偿 |
| 控制轮 | 曝光补偿 ±1/3 EV |

> 机顶**物理曝光补偿拨盘在 App 内不生效**（编码在相机重开后不稳定），请用后拨轮或菜单。

## 二、FN 菜单（v3.9 结构）

**四个选项卡**，选中即显示项目列表：

```
拍摄   设置   延时设置   预设
──────────────────────────────
▌模式              A 光圈优先
 ISO               AUTO 1600 (100-1600)
 快门              1/60
 ...
```

### 操作

| 按键 | 作用 |
|---|---|
| **↑ / ↓** | 只做选择（上下移动项目） |
| **← / →** | 只做选择（切换选项卡） |
| **转盘**（任一） | **修改当前项目参数**，立即写入相机 |
| **确认键** | 执行当前项目（预设保存/载入）；普通参数提示"转盘调整" |
| **FN** | 退出并写相机 |

### 各选项卡内容

| 选项卡 | 项目 |
|---|---|
| **拍摄** | 模式 / ISO /（**ISO 为 AUTO 时**多出 ISO自动下限、ISO自动上限）/ 快门 / 光圈 / 照片格式 / 压缩 / 白平衡 |
| **设置** | 对焦（MF / AF-S / AF-C / AF-A / **DMF**）/ 测光 / 静音 / 防抖 |
| **延时设置** | 间隔 时 / 间隔 分 / 间隔 秒 / 拍摄张数 |
| **预设** | 预设文件 1 / 2 / 3 / 4 |

### 预设文件（进入后编辑）

在「预设」页选中某个文件按 **确认键** 进入，页面变为该文件的参数：

| 项目 | 说明 |
|---|---|
| 间隔 时 / 分 / 秒 | 0–24 时、0–59 分、0–59 秒 |
| 拍摄张数 | 1–9999（转盘 ±1，**快速连转每格 ±10**） |
| 使用场景 | 循环选择：未设置 / 日转夜 / 流云 / 星空 / 车流 / 日出日落 / 潮汐 / 建筑 / 人流 / 花卉 |
| 保存当前参数 | 确认键：把当前间隔+张数+场景存入该文件 |
| 载入该预设 | 确认键：把该文件载入相机 |

**左键** 返回文件列表。列表里会显示摘要，例如 `0:05 × 250 · 日转夜`。

> 间隔下限 5 秒（写卡 2.6 秒 + 重开 0.8 秒 ≈ 3.5 秒循环）。

### ISO 自动范围

- ISO 为 **AUTO** 时，ISO 行显示 `AUTO 1600 (100-1600)`，并额外出现 **ISO自动下限 / ISO自动上限** 两项可调
- ISO 为**手动**时只显示数值，上下限两项自动隐藏

## 三、界面

```
卡 320 张                                   ISO AUTO 1600
┌────────────────────────────────────────────────────────┐
│                      实时取景                           │
├─────────────────────────────────────────────────────────┤
│ A  | ▮▮▮|▮▮▮  0.0    RAW 4000K        f/4.0 1/60 [250]  │
│ ▲▼ 0:05   ◀▶ ×250   🕐 20:50    ▶ ENTER   ◉ 单张        │
└─────────────────────────────────────────────────────────┘
```

- 左上 `卡 N 张` = 按当前格式估算的剩余可拍张数（RAW 41/82MB、JPEG 5MB、RAW+JPEG 46/87MB）
- 右上 `AUTO ISO 1600` = AUTO 时显示相机实时算出的 ISO
- 曝光标尺 **±3EV**，曝光补偿可设到 ±5EV，超出时指针贴边
- 每张拍完相机会重开一次，重开期间黑屏约 **0.83 秒**（HAL 行为，无法消除）

## 四、间隔拍摄怎么用

1. FN → **拍摄**页设 模式（推荐 A 档）、ISO（建议手动固定）、照片格式
2. **延时设置**页设 间隔 时/分/秒 与 拍摄张数
3. ENTER 开始，屏幕显示 `运行中 12/250 下一张 3.2s 已存 12`
4. 拍摄中按 **上键** 循环调暗屏幕（4 档），停止后自动恢复
5. ENTER / 快门 / 删除键 停止

时长换算（25fps）：10 秒视频 = 250 张；5 秒间隔下约 21 分钟。
存储：RAW 每张约 41 MB，250 张 ≈ 10 GB。

## 五、已知限制

| 限制 | 说明 |
|---|---|
| 拍照后仍显示照片 | 相机自己的「自动检视」，App 读不到也改不了；到相机菜单 → 播放 → **自动检视 → 关** |
| 调参数时画面闪一下 | 写参数会重置预览流（约 0.05–0.15 秒），已用 300ms 去抖合并写入 |
| 每张重开相机 | 快门 HAL 只接受"重开后的第一次拍摄"，每张多约 0.83 秒 |
| 间隔下限 5 秒 | 写卡 2.6 秒 + 重开 0.83 秒 ≈ 3.5 秒循环，4 秒以下会跳格 |
| M 档标尺 | 显示曝光补偿而非相机曝光偏差（`ProperExposureLevelCallback` 不回调） |
| 物理 EC 拨盘 | 不支持（编码不稳定） |
| 放大对焦（C2） | 不支持（`getPreviewMagnificationRatio()` 全返回 -10），C2 改作切换预设 |
| 静音快门 | 开启可能降为 12bit，画质优先请关 |
| 使用场景 | 固定列表，相机无输入法，无法自由输入 |

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 提示 `No devices found` | PMCA‑RE 安装问题，检查 USB 线 / 相机是否开机 |
| 相机黑屏卡住 | 曾因纯 RAW 注册 JPEG 回调导致，v0.18 已修 |
| 日志里 `interval skip` | 间隔小于单张耗时，调大间隔 |
| 设置改了但照片没变 | 看日志 `applySettings ... FAILED` |
| 中文变方块 | 日志里看 `font loaded:` 用的哪个字体；系统字体缺失时会退回内置子集 |

日志读取：双击 `4-查看App日志.cmd`（自动找盘符/下载/桌面里的 LOG.TXT，复制到 `A7R2App/logs/`）。

日志：`/sdcard/A7R2APP/LOG.TXT`。
