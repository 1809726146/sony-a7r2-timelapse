索尼延时摄影 · 安装程序 使用说明
────────────────────────────────
双击「索尼延时摄影安装程序.exe」即可。

程序会做四件事：
1. 启动时立刻检测 USB 上有没有索尼相机，并判断它是不是 MTP 模式；
2. 检测到相机后「开始安装」按钮变亮，点它；
3. 从程序内部取出延时摄影 V5.5 安装包（APK 已内嵌，不需要另外放文件），
   通过 PMCA 传到相机并安装；
4. 安装完成后弹窗提示，窗口里同时留一份完整日志。

状态灯含义
  灰点  正在检测
  绿点  已连接（MTP 模式），可以安装
  黄点  检测到相机，但当前是大容量存储模式 → 在相机上改：
        MENU → 设置（第 4 页）→ USB 连接 → 选「MTP」
  红点  未检测到相机 → 检查：相机是否开机、线是否支持数据传输、
        USB 模式是否是 MTP（不是「电脑遥控」、不是「大容量存储」）

需要知道的三件事
1. 程序必须以管理员身份运行（Windows 不允许普通权限访问相机的 USB
   存储端点）。exe 里已经写死 requireAdministrator，双击会弹 UAC，
   点「是」即可。
2. 装完相机可能自动切回大容量存储，如果之后想在电脑上看照片，
   把 USB 模式改回「大容量存储」就能在「此电脑」里看到存储卡。
3. 同目录的「运行环境」文件夹不要删、不要改名，里面是 Python 与 PMCA，
   安装程序靠它和相机通信。可以整个文件夹一起拷到别的电脑上用（Windows 10/11）。

常见报错
  No devices found …   相机掉线或休眠，重新插一次线、唤醒相机再点「重新检测」
  Access denied …      没有以管理员身份运行（正常双击会自动提权，若被 UAC 取消则不会）
  claim_interface …    相机处于「电脑遥控」模式，切回 MTP
  USBError …           换一根支持数据传输的线，或换一个 USB 口（不要用 hub）

安装完成之后
  相机菜单 → 应用程序 → 「延时摄影」；
  建议把相机的「自动检视」设为「关」，避免每张之后弹出回放。
