索尼 A7R II · 延时摄影 App · UI 交互原型

屏幕 640×480（density 1.5 → 427×320 dp）· 按 F 在「预览 / 菜单」间切换 · 方向键、转盘（滚轮）都能操作

操作方式

F预览 ⇄ 菜单
←→菜单里切换选项卡
↑↓选择项目 / 预览里调间隔
滚轮转盘：修改当前项目参数
Enter执行（预设保存 / 载入、进入文件）
Esc预设文件内返回列表
