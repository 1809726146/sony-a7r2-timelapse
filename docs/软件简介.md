## 短介绍（约 100 字，适合列表 / 卡片）

延时摄影是一款运行在索尼 ILCE-7RM2（A7R II）相机内部的应用。它直接调用相机拍摄接口，
按设定的间隔与张数自动连拍，全程不需要手机、遥控器或外接定时器；同时能设置相机原生的
ISO、光圈、快门、照片格式、白平衡、对焦等参数，支持 4 组预设一键切换。

## 完整介绍（约 450 字）

延时摄影是为索尼 ILCE-7RM2（A7R II）开发的机内应用。它以索尼相机应用的形式安装到机身内，
运行时直接接管相机的拍摄能力，因此不需要连接手机、不需要外接定时器，也不会因为
无线断连而中断拍摄。

应用提供完整的两类能力。**一类是拍摄控制**：间隔时间可在 5 秒到 24 小时 59 分 59 秒之间
按「时 / 分 / 秒」精确设置，拍摄张数 1 到 9999 张，开始前有 3 秒倒计时，拍摄中显示进度条、
已拍张数、剩余倒计时与已存张数，并支持屏幕调光以免长时间拍摄时干扰。**另一类是相机参数**：
拍摄模式、ISO（含 AUTO 自动上下限）、快门、光圈、照片格式（JPEG / RAW / RAW+JPEG）、
RAW 压缩、白平衡、对焦方式、测光、防抖、静音快门，全部可以在应用内调整并写入相机。

界面按「拍摄 / 设置 / 延时设置 / 预设」四个选项卡组织，打开即见项目列表；
方向键只负责选择，转盘负责改值，中央键负责执行，避免在小屏幕上误改参数。
四个预设文件可以保存常用的间隔、张数与使用场景，拍摄中按 C2 键即可循环切换。

应用会把运行过程写入相机存储卡上的日志，并按 C1 键随时导出一份日志快照；
左上角实时显示按当前格式估算的剩余可拍张数。

## 功能清单（适合 README / Release 说明）

**拍摄控制**
- 间隔时间：5 秒 – 24:59:59（时 / 分 / 秒分别设置）
- 拍摄张数：1 – 9999（转盘 ±1，快速连转 ±10）
- 3 秒倒计时启动、绝对时间基准调度、跳格保护
- 运行中显示进度条、已拍 / 总数、下一张倒计时、已存张数
- 拍摄中屏幕可 4 档调光，停止后自动恢复

**相机参数**
- 模式（P / A / S / M）、ISO、快门、光圈
- ISO 为 AUTO 时显示自动范围并可调整上限 / 下限
- 照片格式（JPEG / RAW / RAW+JPEG）、RAW 压缩
- 白平衡（AUTO / 2500K–9900K）
- 对焦（MF / AF-S / AF-C / AF-A / DMF）、测光、防抖、静音快门

**易用性**
- 四选项卡菜单，打开即列表，方向键只选择、转盘只改值
- 4 组预设文件，可保存间隔 + 张数 + 使用场景，C2 一键循环切换
- 相机重开后自动重写全部参数，防止被固件改回
- 左上角实时显示剩余可拍张数
- 中文界面，优先使用相机自带中文字体，内置字体兜底

**可诊断性**
- 运行日志写入 SD 卡 `A7R2APP/LOG.TXT`
- 按 C1 生成 `SNAP-时间戳.TXT` 日志快照，便于反馈问题

## 技术特征（面向开发者）

| 项 | 内容 |
|---|---|
| 包名 / 版本 | `com.shenwenjun.a7r2app` v3.9（versionCode 79） |
| 运行环境 | Android 4.1.2 / SDK 16，屏幕 640×480（427×320 dp） |
| 相机接口 | 索尼 Scalar API；参数必须经 `CameraEx.createParametersModifier()` 写入 |
| 构建方式 | 无 Gradle：aapt → javac 1.6 → dx → aapt → zipalign → apksigner（v1 签名） |
| 体积 | APK 133 KB（内置 80 KB 中文字体子集） |
| 拍摄循环 | 拍摄 + 写卡约 2.6 秒，相机重开约 0.83 秒，合计约 3.5 秒/张 |
| 关键限制 | 快门 HAL 每次 open 只接受一次拍摄，因此每张需重开相机；间隔下限 5 秒 |

## 适用人群

- 风光 / 城市 / 星空延时摄影爱好者，希望减少设备与连线
- 需要长时间无人值守拍摄、又不想依赖手机的用户
- 想在机内精确控制曝光与格式、而非只按快门的进阶用户

## 不适用

- 需要高于 5 秒/张的连续高速拍摄（受硬件限制）
- 需要机内直接合成视频（请用电脑端合成）
- 非 ILCE-7RM2 机型（界面与参数按 640×480 与该机型接口适配）
