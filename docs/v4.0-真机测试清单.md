# v4.0 真机测试清单

> 目标：确认新界面能在 ILCE-7RM2 上正常显示，并逐个验证「每一个可交互的选择」。
> 设备：ILCE-7RM2（固件 4.01）｜ APK：`延时摄影-v4.0.apk`（versionCode 80，132 KB）

## 0 准备

1. 双击 `2-安装到相机.cmd` 装机（相机开机、USB 数据线、关掉 Imaging Edge）。
2. 相机 MENU → 应用程序 → 应用程序列表 → 「延时摄影」。
3. 拍完想回看日志：相机卡插电脑，双击 `4-查看App日志.cmd`，或直接看 `X:\A7R2APP\LOG.TXT`。

任何一步失败，把 `LOG.TXT` 最后 60 行发我即可定位。

## 3 每个选项卡的每个项目

按顺序走一遍，每项都要「值能变 / 屏幕上有反馈 / 写入生效」：

**拍摄**（7 项，ISO 为 AUTO 时变 9 项）
1. 模式 A/S/M/P —— 转盘切换，左上模式徽章与预览参数随之变化
2. ISO —— AUTO 时值显示 `AUTO 1600 (100-1600)`
3. ISO 自动下限 / 4. ISO 自动上限 —— 仅 AUTO 时出现
5. 快门、6. 光圈、7. 照片格式、8. 压缩、9. 白平衡

**设置**（4 项）：对焦方式、测光模式、静音快门、防抖

**延时设置**（4 项）：间隔 时 / 分 / 秒、拍摄张数（快转 ±10）

**预设**（文件 1–4 → 文件内 7 项）：间隔 时/分/秒、拍摄张数、使用场景、保存当前参数、载入该预设
